# Beneficiary Service Desk — Prompt Library (Day 5 Project, Example)

**Path:** A (free path) · **Scenario:** Beneficiary Service Desk, prefix `SD`

A beneficiary writes to the desk about visits, cancellations, requests and complaints. The desk agent drafts replies with AI, and a person reviews every reply before it is sent. All data in this project is invented.

The library is in the folder [`PE_Library_Example`](PE_Library_Example/). Start with [`library_index.md`](PE_Library_Example/library_index.md).

## The 10 tasks (✓ = built and approved)

| No. | Task | Goal | Built |
|---|---|---|---|
| 1 | Reply to an inquiry | Write a short, polite reply to an inquiry using only the Desk Facts | ✓ |
| 2 | Summarize a message | Summarize a long message in three lines for the team | ✓ |
| 3 | Classify an inquiry | Label each inquiry as Appointment, Cancellation, Complaint, Status or Other | ✓ |
| 4 | Rewrite a staff draft | Rewrite a rushed or rude staff draft as a calm, polite message | ✓ |
| 5 | Draft a visit reminder | Write a reminder about a booked visit and how to cancel or reschedule | ✓ |
| 6 | Translate a reply | Translate an approved reply between Arabic and English without changing any fact | |
| 7 | Closed-day notice | Write a short notice about a day the desk is closed | |
| 8 | Create an FAQ | Turn five common questions and their facts into a short FAQ list | |
| 9 | Prepare a handoff note | Write a short note for the supervisor when a case needs a person’s decision | |
| 10 | Mask a message | Replace names, phones and emails in a message with codes before it goes to an AI tool | |

## Test results

Each of the five templates scored 5/5 (prompt quality), 6/6 (template quality) and 5/5 (output quality). See [`Test_Results_Report.pdf`](PE_Library_Example/Test_Results_Report.pdf).
